# Vooh

Vooh is an offline-first music player for iOS and Android. It imports and manages local music,
supports offline playback and cache management, and can connect to user-provided online source
plug-ins. The application source code is maintained in a private repository; this public repository
contains product information and signed Android releases only.

## Download

- Android APK: [GitHub Releases](https://github.com/glink25/vooh-music/releases)
- Google Play: coming soon
- App Store: coming soon

Always download APK files from this repository's Releases page and verify the accompanying SHA-256
checksum before installation.

<a id="privacy"></a>

## Privacy

Vooh does not require a Vooh account and does not include advertising or analytics. The music
library, playback history, plug-in subscriptions, cache records, and donation status are stored on
the device. Store donations are processed by Apple or Google; Vooh only keeps a local record that a
purchase completed and does not receive or store payment-card details.

Vooh does not bundle an online music source. If a user adds a third-party source plug-in, the plug-in
can make network requests to the domains it declares or to media URLs returned by those services.
Those requests are subject to the selected service's terms and privacy policy. Removing the plug-in
stops its future use; cached files can be removed from Vooh settings.

Users can remove Vooh's locally stored information by clearing the relevant cache/library data or by
uninstalling the app. Privacy questions can be filed through the Support link above.
